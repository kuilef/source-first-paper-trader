# Source-First Paper Trader: инструкция

Это демонстрационный агент с прозрачными правилами. Он читает официальные объявления Kraken, проверяет сведения о листинге и записывает условную покупку либо объясняет отказ. Все деньги, позиции и результаты виртуальные. Приложение не подключается к кошельку или биржевому счёту и не отправляет реальные ордера.

## Быстрый показ

1. Откройте **Replay lab**. Сценарий **Fresh listing → paper entry & exit** показывает подтверждение, виртуальный вход и последующее закрытие.
2. Нажмите **Run illustrative replay**. Цены и изменённые сведения здесь учебные; время зафиксировано на 9 октября 2026 года. Это не исторический бэктест.
3. В **The decision trail** выберите запись покупки или закрытия. Проверьте имя актива, тикер, фактическую дату начала торгов, время публикации и наблюдения котировки.
4. Раскройте **Policy checks** и **Snapshot & provenance**. Видны причины, исходные ссылки, наблюдения и SHA-256 отпечаток входных данных.
5. Запустите **Recycled announcement → abstain**. Новая публикация не делает старый листинг новым. Повторный запуск заменяет только учебный журнал и не добавляет вторую покупку.

## Живые источники

Перейдите в **Live desk** и нажмите **Start live agent**. Агент самостоятельно проверит последние объявления и при достаточных данных запишет виртуальное действие. **Stop agent** отменяет текущий цикл; опоздавший ответ не меняет журнал.

Объявления проверяются каждые пять минут, открытая позиция — примерно раз в минуту. Работа продолжается только пока страница открыта и браузер её выполняет. После перезагрузки агент всегда остановлен. Если осталась открытая виртуальная позиция, после возобновления используется первая новая котировка. Пропущенные интервалы не изображаются как совершённые сделки.

Для живых данных нужен опубликованный Cloudflare Pages Worker или локальная команда `npm run preview` после сборки. Обычный `npm run dev` запускает интерфейс, загрузку логотипа `/logo.png` и favicon `/favicon.ico`, но не маршруты живых источников. Сбой сети, лимит источника или изменение разметки отображаются как недоступные данные; приложение не подменяет их учебным сценарием.

## Правила и смысл отказов

- **EVENT_TOO_OLD**: фактическая дата торгов старше вчерашнего дня по календарю UTC. Дата публикации учитывается отдельно.
- **EVENT_FUTURE / EVENT_DATE_UNKNOWN**: дата будущая либо в исходной фразе нет однозначных дня, месяца и года.
- **UNSUPPORTED_EVENT**: объявление не соответствует узкому формату уже начавшегося спотового листинга.
- **IDENTITY_UNKNOWN / IDENTITY_CONFLICT**: нет однозначной связи полного названия и тикера либо исходное утверждение ей противоречит.
- **PAIR_MISMATCH / PAIR_NOT_ONLINE**: не подтверждена одна подходящая USD-пара со статусом online.
- **QUOTE_UNAVAILABLE / QUOTE_INVALID / QUOTE_STALE**: котировка отсутствует, некорректна или слишком давно наблюдалась.
- **QUOTE_PREDATES_DISCOVERY**: цена была получена до того, как агент увидел событие.
- **SPREAD_TOO_WIDE / BELOW_MINIMUM**: слишком широкий спред либо после округления не выполнен минимальный размер и лимит бюджета.
- **DUPLICATE_EVENT / POSITION_LIMIT**: событие уже использовано для входа либо уже есть одна открытая позиция.
- **NUMERIC_RANGE / EXIT_VALUE_BELOW_FEE**: значение нельзя безопасно представить в ограниченном формате либо условная комиссия превышает стоимость слишком маленького остатка. Новая сделка не выдумывается.

Начальный виртуальный баланс — 1 000 USD, максимальный полный расход на вход — 25 USD, максимум одна позиция. Комиссия условно равна 0,40%, неблагоприятное проскальзывание — 0,10% на каждой стороне. Количество округляется вниз по точности пары, комиссия вверх до восьми десятичных знаков USD.

Закрытие происходит по первой новой допустимой котировке, когда условная доходность ликвидации достигла −2% или +3%, либо котировка получена не раньше чем через 60 минут после входа. Это не гарантия цены стопа: скачок рынка может дать больший убыток. Ликвидность, очередь ордеров и частичные исполнения не моделируются.

Источник указывает календарную дату, а не точный момент старта. Время наблюдения ответа Ticker не является биржевым временем сделки. Совпадение символа внутри Kraken не доказывает адрес контракта и доступность актива в конкретной стране.

## Журнал, экспорт и восстановление

**Export journal** скачивает JSON с правилами, доказательствами, короткими выдержками, причинами и точным расчётом. **Import journal** проверяет схему, отпечатки, решения и цепочку балансов заново. Импорт открывается отдельно, только для чтения; он не запускает агента и не переходит по ссылкам из файла.

Лимиты импорта: 1 МиБ, 200 записей и глубина JSON 16. Повреждённый или подменённый файл не заменяет текущий журнал. Отпечаток SHA-256 помогает выявить изменения, но не удостоверяет подлинность источника.

**Reset workspace** требует подтверждения. При отмене данные остаются. Перед очисткой сохраните экспорт. Данные хранятся в localStorage этого браузера; удаление данных сайта может удалить журнал. Последнее корректное состояние сохраняется как резервная копия. При повреждении приложение пытается сохранить исходные байты и восстановить копию, а при невозможности открывает чистое остановленное рабочее пространство с сообщением. При нехватке места новые изменения не заменяют последний корректный журнал.

## Локальный запуск

Нужны Node.js 24 LTS и npm:

```sh
npm ci
npm run build
npm run preview
```

Откройте http://127.0.0.1:4173. Проверки: `npm test`, `npm run typecheck`, `npm run lint`, `npm run replay -- --case confirmed`. Для браузерных тестов установите Chromium командой `npx playwright install --with-deps chromium` и запустите `PRODUCTION_PREVIEW=1 npm run test:e2e` после сборки.

Виртуальная прибыль учебного примера не означает доходности стратегии и не является финансовой рекомендацией.

### Загрузка папки без двоичных файлов

В Cloudflare Pages Direct Upload можно выбрать папку `dist/` после `npm run build` либо плоский ZIP после `npm run package`. Все файлы сборки являются текстом UTF-8. В репозитории есть обычные файлы [PNG-логотипа 512×512](../branding/logo.png), [favicon.ico](../branding/favicon.ico) и [SVG-исходника](../branding/favicon.svg). [Скачать PNG для заявки](../branding/logo.png?raw=true) · [Скачать ICO для сайта](../branding/favicon.ico?raw=true). ICO содержит размеры 16, 32, 48, 64, 128 и 256px, полученные из того же PNG. Worker возвращает встроенные копии этих байтов по `/logo.png` с типом `image/png` и `/favicon.ico` с типом `image/x-icon`, а HEAD — только заголовки. Тесты проверяют точное совпадение ответов с файлами репозитория. Не копируйте бинарные файлы в `dist/`: папка сборки остаётся текстовой. Оба маршрута работают в `npm run dev`, Pages preview и standalone Worker.
